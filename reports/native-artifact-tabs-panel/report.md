# 右サイド成果物タブUI 実装検証

## 対象

- 実装基準: `97ed91b461692fc5fa1ef791072a0e7bc259cf82` 時点のSamurai Agent
- 対象: Roomの右サイド成果物パネル、成果物タブ、固定開閉ボタン、メイン領域拡大、下書き保護
- 公開API、Server、DB、認可、成果物データ形式は変更していない

## 実装確認

- Room内で開いた成果物だけをタブへ追加し、同一リソースを重複表示しない。
- タブの×は表示タブだけを閉じ、成果物削除処理を呼ばない。
- 成果物パネルの独立した「仕事へ戻る」ボタンとRoomヘッダー内の重複開閉ボタンを削除した。
- 開閉ボタンを`native-main-window`の右上に固定し、パネル開閉前後で同じ位置を使う。
- 参加者表示とRoomメニューはチャットヘッダーに残し、チャット幅に追従させる。
- 拡大状態はパネル幅設定と分離し、メイン領域全体へ広げる。解除時は分割幅へ戻す。
- 非表示タブの編集状態を含めて保存保護を集約し、Room移動・Workspace移動・パネル閉鎖で下書きを無視しない。
- 成果物から開く操作画面は元のタブを置き換えず、別タブとして追加する。
